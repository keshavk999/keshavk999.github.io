# How to update the CV on the website (private note for Keshav)

This file is not published. GitHub Pages skips files whose names start with "_".

## The rule
The website always offers the file in this folder named exactly:

    cv/Keshav_Kumar_CV.pdf

The name is case-sensitive: capital K, capital C, capital V, underscores, lower-case ".pdf".

## Steps to replace the CV
1. Save your new CV as a PDF and rename it to `Keshav_Kumar_CV.pdf`.
2. Open the repository on GitHub: keshavk999/Keshavkumar-Portfolio.
3. Open the `cv` folder and select **Add file → Upload files**.
4. Drag in the new `Keshav_Kumar_CV.pdf`. GitHub replaces the old file with the same name.
5. Write a short commit message, for example "Update CV Nov 2026", then select **Commit changes**.
6. Wait 1–2 minutes, then test the Download CV button on the Home page.
   If you still see the old CV, refresh with Ctrl+F5 (Windows) or Cmd+Shift+R (Mac).

## Do not
- Do not rename the file, or the Download CV buttons will break.
- Do not keep a second CV in this folder. Only one CV should be online.
